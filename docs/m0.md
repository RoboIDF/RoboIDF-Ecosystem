# CSV 离线适配入门

`adapter.py` 是可运行的第三方接入示例，直接导入 Core 的 Dataset/fit/rollout_rmse，不复制合同、不修改 Core。该示例没有硬件命令接口，不授予 L2 真机支持。

运行 `pixi run demo`：生成合成训练/验证 CSV → 通过适配器读取 → Core 拟合 → 独立保留轨迹自由回放 → artifacts/adapter.json。CSV 与报告均为可再生成产物。

CSV 列必须按顺序为 `time_s,velocity_m_s,effort_n`。时间严格递增、等间隔且有限；速度 m/s、输入力 N；末行只包含终态，因此 effort_n 必须为空。至少 4 行，非末行不能缺值。不自动猜测单位、插值、时钟同步或控制命令含义。

```python
from adapter import read_csv
from roboidf import fit
training = read_csv('training.csv', split='train', seed=17)
model = fit(training)
```

接入真实离线日志之前，必须确认已测力而非未校准的命令、采样时钟、单位、传动与反馈语义。当前质量阻尼模型不适用于直接把机械臂角度/扭矩日志作为输入。
